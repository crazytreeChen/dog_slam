# 离线雷达扫描匹配——独立脚本实施计划

## 一、目标

编写独立离线脚本 `DevEco_scan_matcher.py`，整合：
1. 多帧扫描合并 + FRF过滤
2. 似然场全局粗搜（Top-K候选）
3. **光线投射180度消歧**（核心改进）
4. ICP精调
5. 生成标记图片（以DevEco_开头命名）

所有方法内联到单文件，不依赖外部模块（仅numpy/cv2/scipy/matplotlib）。

同步改进在线节点 `auto_initial_pose_calibrator.py`。

## 三、DevEco_scan_matcher.py 设计

### 3.1 流程

Step 1: 加载 NPZ 数据
Step 2: 多帧扫描合并 + FRF 过滤
Step 3: 构建似然场
Step 4: 全局粗搜 (coarse grid + NMS) -> Top-K
Step 5: 精搜 (fine grid around Top-K) -> Top-N
Step 6: 光线投射 180度消歧 -> 唯一候选
Step 7: ICP 精调
Step 8: 输出结果 + 生成标记图片

用法:
  python DevEco_scan_matcher.py
  python DevEco_scan_matcher.py --data path/to/debug_match_data.npz
  python DevEco_scan_matcher.py --coarse-step 1.5 --top-k 10 --ray-lambda 0.3

### 3.2 核心方法清单

| 方法 | 功能 | 来源 |
|------|------|------|
| `load_data(npz_path)` | 加载NPZ | 复用opencode |
| `frf_filter_per_frame(ranges, ...)` | 前方射线优先过滤 | 复用opencode |
| `merge_scans(frame_ranges, frame_tfs, ...)` | 合并多帧到odom系 | 复用opencode |
| `build_likelihood_field(map_data, info)` | 距离场->似然场 | 复用opencode |
| `score_at_pose(points, cx, cy, yaw, lf, info)` | 似然场评分 | 复用opencode |
| `global_coarse_search(...)` | 粗搜+NMS | 复用opencode+改进 |
| `fine_search_refine(...)` | 精搜 | 复用opencode+改进 |
| **`ray_cast_single(cx, cy, yaw, ranges, angles, map_data, info, n_rays)`** | **单候选光线投射MAE** | **新写** |
| **`ray_cast_disambiguate(candidates, frame_ranges, ...)`** | **180度消歧** | **新写** |
| `icp_refine(points, cx, cy, yaw, map_data, info)` | ICP精调 | 复用opencode |
| `create_visualization(...)` | 生成6面板标记图片 | 新写 |

### 3.3 光线投射核心算法

ray_cast_single: 从候选位姿发射射线，在栅格地图上Bresenham步进直到碰到occ(100)，记录理论测距，计算与实际scan测距的MAE。

关键细节:
- 均匀采样120条射线（从原始ranges中等间距取）
- 跳过超量程射线(range>=30m)
- unknown(-1)和free(0)继续步进不停止
- ROS row约定: row = H-1-(y-oy)/res
- 返回 (mae, valid_ratio)

### 3.4 消歧逻辑

ray_cast_disambiguate:
- 使用第一帧原始ranges（保留空旷射线信息，合并scan丢失此信息）
- 对每个候选同时评估yaw和yaw+180度
- 综合分 = 似然场分 - lambda * MAE (lambda推荐0.3)
- 选择综合分更高的方向
- 输出带消歧标注的候选列表

### 3.5 标记图片（6面板）

1. (a) 合并扫描形状: odom系点云 + 质心标记 + 帧位姿轨迹
2. (b) 全局搜索候选: 地图 + Top-K候选位姿箭头 + GT星标
3. (c) 光线投射消歧: 最佳候选+180度镜像的射线对比图
4. (d) 最佳结果叠加: 地图 + 对齐扫描点云 + 位置箭头
5. (e) GT对比: GT对齐 vs 估计对齐 叠加对比
6. (f) 报告面板: 数值结果 + 误差统计 + 消歧过程日志

## 四、在线节点改进


## 七、风险与兼容性

1. 光线投射性能: Top-10候选约120K次地图查询，预计<0.5s，可接受
2. unknown区域: 射线连续3个unknown后停止不计入MAE
3. 单帧vs多帧: 光线投射用第一帧原始ranges，合并scan用于似然场搜索
4. row索引: 统一用ROS标准 row = H-1-(y-oy)/res
5. scipy可选: ICP依赖scipy，光线投射仅需numpy

## 八、回滚

- 新增脚本，不修改现有脚本
- 在线节点改动限定在新增方法+匹配末尾插入消歧调用
- 可通过 ray_cast_enabled: false 关闭消歧
